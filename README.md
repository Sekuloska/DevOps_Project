Проектот претставува едноставна Spring Boot апликација за управување со листа на контакти која овозможува додавање и бришење на истите преку веб-интерфејс. За база на податоци се користи PostgreSQL, а апликацијата е контејнеризирана и оркестрирана со Docker и Kubernetes. Преку Docker Compose се оркестрираат апликацијата и базата, додека пак Kubernetes се користи за управување со апликацијата во кластер. CI/CD процесот е имплементиран преку GitHub Actions за автоматско генерирање и поставување на Docker имиџи на DockerHub.

Алатки кои ги користев во проектот се Spring Boot за развој на back-end апликацијата, PostgreSQL за базата на податоци, Docker за контејнеризација на апликацијата, Docker Compose за оркестрирање на апликацијата и базата, Kubernetes за оркестрација на апликацијата во кластер, Nginx Ingress за HTTP рутирање во Kubernetes и GitHub Actions за автоматизација на CI/CD процесот.
